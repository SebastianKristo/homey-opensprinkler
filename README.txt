Control your OpenSprinkler irrigation controller from Homey.

Add your OpenSprinkler controller with its IP address and password, then add each zone as its own device. Start and stop zones, see how much time is left, and use quick buttons for 5, 10, 15, 30 or 60 minutes.

Features:
- Turn the controller on or off, set rain delay and adjust the water level
- Rain sensor and running zones shown on the controller device
- Drip or sprinkler icon for each zone
- Program overview on the controller device, and create, edit, delete and run OpenSprinkler programs from the app settings
- Water used by each zone in its last run
- Flow cards: run or stop a zone, stop all zones, run a program, enable or disable a program, set rain delay and water level
- Two dashboard widgets: one for the controller and one for the zones, with live countdown
- Water metering: choose a water meter in the app settings (for example a Sonoff Zigbee water meter). Flow and consumption are attributed to the zone that is running, so every zone gets its own flow and consumption sensors.
- Master valve: choose a valve that is turned on every time a zone starts, and turned back on if it closes while a zone is watering.

Works with OpenSprinkler firmware 2.1.x and newer on the local network.

This app is not affiliated with OpenSprinkler / OpenThings.
